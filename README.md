# Shepherd IT

A simple, responsive business card website for home and small-business technology support in Henderson and the surrounding Las Vegas area.

## Run locally

Requires Node.js 20 or newer. No install step is needed.

```sh
npm start
```

Open [http://localhost:3000](http://localhost:3000). The page follows the visitor's system light or dark preference.

## Update before launch

Confirm the business name, contact information, and exact service list in `dist/index.html` before sharing the site with customers.
